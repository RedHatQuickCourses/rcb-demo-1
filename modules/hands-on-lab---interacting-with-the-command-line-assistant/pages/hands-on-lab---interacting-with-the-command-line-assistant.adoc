#   Hands-on Lab - Interacting with the Command-Line Assistant

**Hands-on Lab - Interacting with the Command-Line Assistant**

This hands-on lab provides practical exercises to utilize the command-line assistant powered by RHEL Lightspeed for various tasks on RHEL systems. The lab covers the following key points:

- **Setting up a test environment**: Instructions to prepare a suitable RHEL environment for interacting with the command-line assistant.
- **Practical exercises**: Step-by-step guidance on how to ask questions, attach files, check interaction history, redirect command output, enable terminal activity capture, and submit feedback to the command-line assistant.
